# DevTool UI App

Modern, scalable frontend application built with a production-grade stack.  
Designed as a reusable UI foundation for building high-quality web applications.

> ⚡ Focus: Performance, Scalability, and Developer Experience

##  Live Demo

## Project Overview

DevTool UI App adalah boilerplate + design system frontend yang siap dipakai untuk:

- Dashboard SaaS
- Internal tools
- Admin panel
- Data visualization apps

Menggunakan pendekatan component-driven architecture dengan fokus pada reusability dan maintainability.

---

## Tech Stack

- React 19
- Vite 7
- TypeScript
- Tailwind CSS
- shadcn/ui + Radix UI
- Recharts
- React Hook Form + Zod

---

## Key Features

- Reusable component system (40+ components)
- Clean & scalable structure
- Dark mode support
- Type-safe forms
- Responsive design
- Accessible UI
- Production-ready
